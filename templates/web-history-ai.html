1. Introduction

While the Internet serves as the physical and transport network layer of linked hardware devices, the World Wide Web (WWW) is an application-level platform constructed on top of this global network. Invented in 1989 by Sir Tim Berners-Lee, the Web provides a unified workspace where documents, images, and resources are identified by addresses and interconnected by hypertext links. The Web evolved the Internet from terminal-based commands reserved for specialized academic networks into an intuitive, visually rich ecosystem accessible to the general public.

3. Key Technologies

Core Web Standards

HTML (HyperText Markup Language)
The foundational formatting language utilized to define structural hierarchy, text markup, media embeds, and interactive hyperlinks across web pages.
HTTP (HyperText Transfer Protocol)
The primary application-layer protocol defining structured request-and-response transactions between user client browsers and hosting web servers.
URL (Uniform Resource Locator)
The standard global addressing scheme designed to uniquely reference individual documents, assets, and services host-wide.
