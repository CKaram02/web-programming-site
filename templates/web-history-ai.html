1. Introduction

While the Internet provides the global network infrastructure, the World Wide Web (WWW) is an information-sharing application built on top of that infrastructure. Invented in 1989 by Sir Tim Berners-Lee, the Web allows users to navigate between documents and media using clickable hyperlinks. It transformed the Internet from a command-line network used primarily by academics and researchers into a visually accessible platform open to the public.

3. Key Technologies

Core Web Standards

HTML (HyperText Markup Language)
The standard formatting language used to structure text, images, and links on web pages.
HTTP (HyperText Transfer Protocol)
The application-layer communication protocol that defines how client browsers request resources from web servers.
URL (Uniform Resource Locator)
The unique standard address format used to locate documents and resources anywhere on the Web.
