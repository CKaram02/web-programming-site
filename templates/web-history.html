The History of the World Wide Web

The World Wide Web is an Internet-based system of interlinked hypermedia documents[cite: 2]. Developed in 1989 by CERN scientist Tim Berners-Lee for physics document sharing, it operates as an application layer on network infrastructure[cite: 2]. After CERN released its source code publicly in 1993, this research utility became an open, global information network[cite: 2].

Timeline of the World Wide Web

  • 1989: The Web proposal
    Tim Berners-Lee proposed linking documents across computers via hypertext. (Source: CERN Internal Report, March 1989)[cite: 2]
  • 1990: First server, browser, and page built
    Berners-Lee developed HTML, HTTP, URLs, the first web server, and the WorldWideWeb browser. (Source: CERN document, Nov 12, 1990)[cite: 2]
  • 1993: CERN releases WWW code to the public domain
    CERN made core Web software open and royalty-free, igniting rapid growth. (Source: Official CERN Declaration, April 30, 1993)[cite: 2]
  • 1993: NCSA Mosaic browser launch
    Marc Andreessen’s team released Mosaic, popularizing inline images and the public web boom. (Source: NCSA, Univ. of Illinois, 1993)[cite: 2]
  • 1994: Founding of the W3C
    Berners-Lee established the World Wide Web Consortium to maintain open web standards. (Source: MIT Press Release, Oct 1994)[cite: 2]

Key Technologies of the Web

  • HTML (HyperText Markup Language): The markup language used to structure and link web pages. (Source: Tim Berners-Lee, 1993 IETF Draft)[cite: 2]
  • HTTP (HyperText Transfer Protocol): The transfer protocol defining how browsers request and receive data from web servers. (Source: RFC 1945)[cite: 2]
  • URL (Uniform Resource Locator): Unique web address targets assigned to every document or resource. (Source: RFC 1738)[cite: 2]
