The History of the World Wide Web

{% endblock %} {% block main %}

The World Wide Web (WWW) is an information space built on top of the underlying Internet infrastructure, enabling documents, images, and resources to be connected via hypermedia links and accessed using unique web addresses. Invented in 1989 by British scientist Sir Tim Berners-Lee while working at CERN (the European Organization for Nuclear Research), the Web was designed to solve complex information-sharing challenges among researchers spread across international institutions. Following CERN's landmark decision to release the core Web source code into the public domain royalty-free in April 1993, the Web quickly grew from an academic document retrieval system into a open media ecosystem that transformed modern life.

Timeline of the World Wide Web

  • 1989: The Web proposal — Tim Berners-Lee authored a proposal titled "Information Management: A Proposal" at CERN, outlining an information management system based on linked hypertext.
  • 1990: First server, browser, and page built — Berners-Lee wrote the core standards (HTML, HTTP, and URLs) and built the world's first web server (running on a NeXT Computer) and web browser (named WorldWideWeb).
  • 1993: CERN releases WWW code to the public domain — On April 30, CERN declared the core Web software open and royalty-free, allowing developers worldwide to create free software, servers, and browsers.
  • 1993: NCSA Mosaic browser launch — Marc Andreessen and his team at NCSA created the Mosaic browser, popularizing the Web by introducing user-friendly graphical interfaces and inline image rendering.
  • 1994: Founding of the W3C — Tim Berners-Lee established the World Wide Web Consortium (W3C) at MIT to coordinate open technical standards, ensuring long-term web interoperability and growth.

Key Technologies of the Web

  • HTML (HyperText Markup Language): The standard markup language used to structure web documents, incorporating elements like headings, paragraphs, forms, and embedded media, interconnected via clickable hyperlinks.
  • HTTP (HyperText Transfer Protocol): An application-layer network protocol engineered for transmitting hypermedia documents. It governs structured request-and-response interactions between client browsers and server systems.
  • URL (Uniform Resource Locator): A uniform address specification used to identify and locate unique documents, assets, and web resources across the global network.
