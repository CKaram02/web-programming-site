1. Introduction

The Internet is a global network of interconnected computer networks that communicate using standardized protocols. Unlike a single physical hardware device or isolated system, it serves as the underlying digital infrastructure that allows data packets to travel instantly across the globe. Emerging from Cold War military research and academic collaboration in the late 20th century, the Internet grew from connecting a few university mainframe computers to establishing the foundation for global communication, finance, and daily digital life.

3. Key Technologies

Foundational Building Blocks

Packet Switching
A method of slicing data streams into smaller blocks (packets) containing header routing information so multiple connections can share the same channel.
TCP/IP
The foundational communication protocol suite; IP handles packet addressing and routing while TCP manages reliable transfer and error checking.
Domain Name System (DNS)
A distributed hierarchical database system that maps human-friendly domain names to numerical IP addresses.
