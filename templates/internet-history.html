The History of the Internet

The Internet is a global system of interconnected computer networks that facilitates communication between devices worldwide[cite: 1]. Originally conceived in the late 1950s as a U.S. government initiative to engineer a resilient communication network, the project materialized as ARPANET, connecting select academic and research institutions[cite: 1]. Through foundational developments such as packet switching and the TCP/IP protocol suite, ARPANET incrementally evolved into a decentralized global infrastructure[cite: 1]. The following timeline outlines the key historical and technical milestones of this evolution[cite: 1].

Timeline of the Internet

  • 1969: ARPANET goes online
    First operational packet-switching network created by ARPA. (Source: BBN Report No. 1822, 1969)[cite: 1]
  • 1971: First network email sent
    Ray Tomlinson introduced message sharing across computers using the @ symbol. (Source: Raytheon BBN Historical Archives)[cite: 1]
  • 1974: Creation of TCP/IP
    Vint Cerf and Bob Kahn designed TCP/IP as a universal communication language. (Source: IEEE Trans. Comm., Vol. COM-22, No. 5)[cite: 1]
  • 1983: The TCP/IP Cutover
    ARPANET mandated TCP/IP on Jan 1, marking the birth of the modern Internet. (Source: RFC 801, Jon Postel)[cite: 1]
  • 1984: Domain Name System (DNS) established
    Paul Mockapetris created DNS, mapping numerical IP addresses to human-readable names. (Source: RFC 882 & 883)[cite: 1]

Key Technologies of the Internet

  • Packet Switching: Splits data into small chunks that travel independently and reassemble at the destination. (Source: Paul Baran, 1964)[cite: 1]
  • TCP/IP: The protocol suite where IP routes data and TCP ensures complete, ordered delivery. (Source: Cerf & Kahn, 1974 / RFC 791 & 793)[cite: 1]
  • DNS (Domain Name System): Converts domain names (e.g., google.com) into numerical IP addresses. (Source: Paul Mockapetris, RFC 1034 & 1035)[cite: 1]
