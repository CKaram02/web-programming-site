The History of the Internet

Home | Web History

The Internet is a global system of interconnected computer networks that facilitates communication between devices worldwide[cite: 1]. Originally conceived in the late 1950s as a U.S. government initiative to engineer a resilient communication network, the project materialized as ARPANET, connecting select academic and research institutions[cite: 1]. Through foundational developments such as packet switching and the TCP/IP protocol suite, ARPANET incrementally evolved into a decentralized global infrastructure[cite: 1]. The following timeline outlines the key historical and technical milestones of this evolution[cite: 1].

Timeline of the Internet

  • 1969: ARPANET goes online — First operational packet-switching network created by ARPA[cite: 1].
  • 1971: First network email sent — Ray Tomlinson introduced message sharing across computers using the @ symbol[cite: 1].
  • 1974: Creation of TCP/IP — Vint Cerf and Bob Kahn designed TCP/IP as a universal communication language[cite: 1].
  • 1983: The TCP/IP Cutover — ARPANET mandated TCP/IP on Jan 1, marking the birth of the modern Internet[cite: 1].
  • 1984: Domain Name System (DNS) established — Paul Mockapetris created DNS, mapping numerical IP addresses to human-readable names[cite: 1].

Key Technologies of the Internet

  • Packet Switching: Splits data into small chunks that travel independently and reassemble at the destination[cite: 1].
  • TCP/IP: The protocol suite where IP routes data and TCP ensures complete, ordered delivery[cite: 1].
  • DNS (Domain Name System): Converts domain names (e.g., google.com) into numerical IP addresses[cite: 1].
